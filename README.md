# VectorDAQ Testlab UI

Standalone dark laboratory DAQ and signal analysis interface with a live Three.js waterfall chart.

## Run

```sh
node industrial-daq-ui/server.mjs
```

Then open:

```txt
http://127.0.0.1:4173
```

The chart supports pointer-driven cursor updates, drag orbit, and wheel zoom. Generated verification screenshots are saved beside the source files.
